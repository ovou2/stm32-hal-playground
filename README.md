# stm32-hal-playground

STM32 HAL 库外设驱动学习笔记与最小可运行例程集。

每个外设一个独立文件夹，包含：能跑通的例程 + 一页笔记（原理 / HAL 关键函数 / 踩过的坑）。

## 硬件平台

| 项目 | 说明 |
|------|------|
| 开发板 | STM32F103C8T6 最小系统板 |
| 下载器 | ST-Link V2 |
| 开发环境 | STM32CubeIDE / Keil MDK-ARM |

## 我的笔记

每个例程文件夹里都有一个 `NOTES.md`，记录三件事：

1. **原理** —— 这个外设在硬件上是怎么工作的
2. **HAL 关键函数** —— 用到了哪几个函数，各自什么作用
3. **踩过的坑** —— 遇到的问题、怎么定位的、最后怎么解决的
