## ⭐ 踩过的坑

> 只记真实踩到的。这比知识点更能说明做过什么。

**01-GPIO-LED**

- **Keil 下载完程序不运行** —— 没勾 `Reset and Run`，MCU 停在暂停状态。拔插 ST-Link（= 重新上电）才跑起来，容易误判成代码或硬件问题。定位方法：下载后按板子 RESET 键
- **LED 必须串限流电阻** —— 不串时引脚电流可达 20~30mA，超过 STM32 引脚的 ±25mA 绝对上限，会慢慢打坏引脚
- **PA1 上没有板载 LED** —— 蓝板的板载可编程 LED 在 PC13，且低电平点亮；PA1 必须外接

**02-GPIO-button**

- **消抖只延时、没二次确认** —— 缺了延时后的复查，抖动期的一次误读就会被当成真按下
- **`RESET`/`SET` 不是 HAL 的枚举** —— 那是 CMSIS 的 `FlagStatus`，应写 `GPIO_PIN_RESET`/`GPIO_PIN_SET`
- **`while(读到低);` 是阻塞等待** —— 按住不松手主循环就卡死，轮询式的固有缺陷

**03-EXTI-KEY**

- **★ 改成 EXTI 模式时，Pull 被 CubeMX 悄悄重置** —— `Pull-up` → `No pull-up/pull-down`，引脚悬空 → 中断要么不来要么乱来
- **★ 时间戳变量写成 `uint16_t`** —— 开机 **65.5 秒后回绕**，消抖彻底失效。现象：刚上电正常，挂机一分钟后发疯
- **★ 松手瞬间的"假下降沿"** —— 触点断开时也会弹跳，人手按键 100~300ms 超出 50ms 窗口 → 「按住亮、松手灭」

**04-TIMER-LED**

- **业务代码写在 `USER CODE` 标记外面** —— `SysTick_Handler` 由 CubeMX 生成，标记外的行重新生成时会被删掉
- **SysTick ≠ TIM** —— SysTick 是内核时基，全芯片一个、做不了 PWM；项目里调光/舵机/测频全靠 TIM

**05/06-UART**

- **★ 回调里忘了重新挂接收** —— 接收中断是"一次性"的，不重挂只能收到第一帧
- **★ 变长命令解析必须做越界保护** —— 发杂鱼数据时 count 会冲出缓冲区，往数组外写会破坏相邻内存
- **★ `printf` 重定向要勾 `Use MicroLIB`** —— 不勾走"半主机"通道，串口无输出且不报错

详细定位过程见各工程的 `NOTES.md`。
