## ⭐ 踩过的坑

> 只记真实踩到的。这比知识点更能说明做过什么。

**01-GPIO-LED**

- **Keil 下载完程序不运行** —— 没勾 `Reset and Run`，MCU 停在暂停状态。拔插 ST-Link（= 重新上电）才跑起来，容易误判成代码或硬件问题。定位方法：下载后按板子 RESET 键
- **LED 必须串限流电阻** —— 不串时引脚电流可达 20~30mA，超过 STM32 引脚的 ±25mA 绝对上限，会慢慢打坏引脚
- **PA1 上没有板载 LED** —— 蓝板的板载可编程 LED 在 PC13，且低电平点亮；PA1 必须外接

详细定位过程见 `01-GPIO-LED/NOTES.md`。
